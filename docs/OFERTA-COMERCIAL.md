# Oferta de Hefesto
| Servicio | Alcance a cotizar |
|---|---|
| Implementación | Instancia, catálogos, roles y capacitación |
| Inventario inicial | Levantamiento físico, depuración y carga de bienes |
| Etiquetado | Diseño/prueba/impresión de etiquetas y asociación a equipos |
| Operación | Actualizaciones, respaldo, pruebas de recuperación y soporte |
| Auditoría periódica | Comparación física con registro y reporte de diferencias |

Separar instalación de levantamiento físico: este último depende de ubicaciones, cantidad de bienes y acceso. Cobrar integraciones/automatizaciones como alcance adicional. Definir límites de soporte y horarios; no prometer24/7 sin cobertura real.

El producto es gestión de activos TI. Para ventas, compras, stock comercial y contabilidad usar el sistema de negocio apropiado; no presentar este paquete como sustituto completo de un ERP.

Posibles ampliaciones a evaluar: API para sincronizar usuarios, conexión con mesa de ayuda, descubrimiento de equipos mediante herramientas específicas y reportes hacia Odoo. No están implementadas ni conectadas en este ZIP.
